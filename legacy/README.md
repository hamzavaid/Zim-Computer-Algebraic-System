# Legacy Zim Implementation

This directory contains the complete pre-overhaul JavaScript implementation and its original data files. It was moved here during the Zim 2.0 Week 0 migration.

The files are retained only for historical reference, behavior mining, and regression comparison. Nothing under `packages/core/src` may import this directory. The old package manifest is preserved as `legacy/package.json`; commands documented in the root README apply to the new TypeScript system instead.
